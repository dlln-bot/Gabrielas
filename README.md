# Gabrielas · Rörelsens hus

Ny webbplats för **gabrielas.se** — ett hus för dans i alla former i Vällingby. Gabrielas Balett är en av inriktningarna, tillsammans med Jazz & Contemporary, Orientalisk dans, Små dansare, Senior i rörelse och Street & Hiphop.

## Utveckling

```bash
npm install
npm run dev
```

Byggs med Vite, React, Tailwind CSS 4, Framer Motion och Lenis. Innehållet (inriktningar, kurser, schema, pedagoger, aktiviteter) ligger i `src/data.ts`.

Varje push till `main` byggs och publiceras automatiskt på GitHub Pages.
